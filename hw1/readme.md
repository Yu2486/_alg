# 習題 1：計算 2 的 n 次方與執行效率比較

## 一、作業目的

本次作業使用四種不同的方法計算 2 的 n 次方，並比較每一種方法的執行效率。

測試條件：

```python
n = 100
```

四種方法分別為：

1. 方法 1：直接使用 Python 的次方運算。
2. 方法 2a：使用遞迴加法。
3. 方法 2b：使用遞迴乘法。
4. 方法 3：使用遞迴加查表。

透過這次實驗，可以了解不同演算法的時間複雜度，以及重複計算對程式執行效率的影響。

---

## 二、方法 1：直接使用次方運算

程式碼：

```python
def power2n_method1(n):
    return 2 ** n
```

這個方法直接使用 Python 內建的次方運算，計算結果非常簡單。

例如：

```python
print(power2n_method1(3))
```

輸出：

```text
8
```

因為：

```text
2^3 = 8
```

這種方法不需要自己撰寫遞迴，程式碼簡單，而且通常有很好的執行效率。

---

## 三、方法 2a：使用遞迴加法

數學公式：

```text
2^n = 2^(n-1) + 2^(n-1)
```

程式碼：

```python
def power2n_method2a(n):
    if n == 0:
        return 1

    return power2n_method2a(n - 1) + power2n_method2a(n - 1)
```

這個方法使用遞迴，每次都會呼叫兩次相同的函式。

例如：

```text
2^3 = 2^2 + 2^2
```

接著兩個 `2^2` 又會分別計算兩次 `2^1`。

因此，同一個子問題會被重複計算很多次。

時間複雜度約為：

```text
O(2^n)
```

當 `n = 100` 時，遞迴呼叫的數量非常龐大，通常無法在合理時間內完成。

這個方法雖然容易理解，但是執行效率很差。

---

## 四、方法 2b：使用遞迴乘法

數學公式：

```text
2^n = 2 * 2^(n-1)
```

程式碼：

```python
def power2n_method2b(n):
    if n == 0:
        return 1

    return 2 * power2n_method2b(n - 1)
```

這個方法同樣使用遞迴，但每次只呼叫自己一次。

例如：

```text
2^3 = 2 * 2^2
    = 2 * 2 * 2^1
    = 2 * 2 * 2 * 2^0
    = 8
```

每次只需要計算一個子問題，不會產生方法 2a 的大量重複計算。

時間複雜度為：

```text
O(n)
```

當 `n = 100` 時，大約需要 100 層遞迴，因此能夠快速完成計算。

---

## 五、方法 3：使用遞迴加查表

方法 3 使用遞迴搭配查表，將已經計算過的結果儲存起來，避免重複計算。

程式碼：

```python
power2n_table = {0: 1}

def power2n_method3(n):
    if n not in power2n_table:
        power2n_table[n] = (
            power2n_method3(n - 1) + power2n_method3(n - 1)
        )

    return power2n_table[n]
```

其中：

```python
power2n_table = {0: 1}
```

代表已知：

```text
2^0 = 1
```
