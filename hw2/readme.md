# 習題 2：求解遞迴方程式與演算法複雜度

## 作業目的

本作業分析四個遞迴方程式，求出精確公式，並判斷各自的時間複雜度。

---

## 第 1 題

題目：

```text
T(n) = T(n-1) + 8
T(1) = 1
```

逐步展開：

```text
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = T(n-3) + 8 + 8 + 8
     = ...
     = T(1) + 8(n-1)
```

因為 `T(1) = 1`：

```text
T(n) = 1 + 8(n-1)
     = 8n - 7
```

**精確解：**

```text
T(n) = 8n - 7
```

**時間複雜度：**

```text
Θ(n)，也就是 O(n)
```

每次只增加固定的 8，總共約增加 n 次，因此是線性成長。

---

## 第 2 題

題目：

```text
T(n) = 2T(n-1) + 9
T(1) = 1
```

逐步展開：

```text
T(n) = 2T(n-1) + 9
     = 2[2T(n-2) + 9] + 9
     = 4T(n-2) + 18 + 9
     = 8T(n-3) + 36 + 18 + 9
     = ...
```

展開到 `T(1)`：

```text
T(n) = 2^(n-1)T(1) + 9(1 + 2 + 4 + ... + 2^(n-2))
```

利用等比級數：

```text
1 + 2 + 4 + ... + 2^(n-2) = 2^(n-1) - 1
```

又因為 `T(1) = 1`：

```text
T(n) = 2^(n-1) + 9(2^(n-1) - 1)
     = 10 * 2^(n-1) - 9
     = 5 * 2^n - 9
```

**精確解：**

```text
T(n) = 5 * 2^n - 9
```

**時間複雜度：**

```text
Θ(2^n)，也就是 O(2^n)
```

每一層會將前一項乘以 2，因此呈指數成長。

---

## 第 3 題

題目：

```text
T(n) = 2T(n/2) + 1
T(1) = 1
```

本題假設 `n` 是 2 的次方，例如 `1、2、4、8、16`。

使用遞迴樹分析：

| 層數 | 節點數 | 每個節點的額外成本 | 該層總成本 |
|---|---:|---:|---:|
| 0 | 1 | 1 | 1 |
| 1 | 2 | 1 | 2 |
| 2 | 4 | 1 | 4 |
| ... | ... | ... | ... |
| 最後一層 | n | 1 | n |

最後一層有 `n` 個基本問題，每個基本問題成本為 `T(1) = 1`，所以葉節點成本總和是 `n`。

所有內部節點的額外成本總和為：

```text
1 + 2 + 4 + ... + n/2 = n - 1
```

所以：

```text
T(n) = n + (n - 1)
     = 2n - 1
```

**精確解（n 為 2 的次方）：**

```text
T(n) = 2n - 1
```

**時間複雜度：**

```text
Θ(n)，也就是 O(n)
```

也可以使用主定理驗證：`a = 2`、`b = 2`、`f(n) = 1`，因此 `n^(log_b(a)) = n`，可得 `Θ(n)`。

---

## 第 4 題

題目：

```text
T(n) = T(n/2) + 1
T(1) = 1
```

同樣假設 `n` 是 2 的次方。

逐步展開：

```text
T(n) = T(n/2) + 1
     = T(n/4) + 2
     = T(n/8) + 3
     = ...
```

當除以 2 共 `k` 次後，會到達 1：

```text
n / 2^k = 1
2^k = n
k = log2(n)
```

因此：

```text
T(n) = T(1) + log2(n)
     = 1 + log2(n)
```

**精確解（n 為 2 的次方）：**

```text
T(n) = 1 + log2(n)
```

**時間複雜度：**

```text
Θ(log n)，也就是 O(log n)
```

每次把問題規模減半，因此只需要對數層的遞迴。

---

## 四題答案整理

| 題目 | 精確解 | 時間複雜度 |
|---|---|---|
| 1 | `T(n) = 8n - 7` | `Θ(n)`，也就是 `O(n)` |
| 2 | `T(n) = 5 * 2^n - 9` | `Θ(2^n)`，也就是 `O(2^n)` |
| 3 | `T(n) = 2n - 1`（n 為 2 的次方） | `Θ(n)`，也就是 `O(n)` |
| 4 | `T(n) = 1 + log2(n)`（n 為 2 的次方） | `Θ(log n)`，也就是 `O(log n)` |

## 結論

第 1 題每次只增加固定的 8，因此是線性複雜度 `Θ(n)`。

第 2 題每次將前一項乘以 2，因此是指數複雜度 `Θ(2^n)`。

第 3 題每層的總成本會加倍，直到葉節點層；所有節點加總後得到 `2n - 1`，因此是線性複雜度 `Θ(n)`。

第 4 題每次把問題大小除以 2，所以只需要 `log2(n)` 層，複雜度是 `Θ(log n)`。
