# 第六週習題：Lambda Calculus 解譯器

## 一、作業目的

本作業實作一個簡單的 Lambda Calculus 解譯器，可以讀取 Lambda Calculus 表達式，逐步進行 β-reduction（Beta 化簡），並顯示每一步的完整計算過程。

程式使用有名稱（named variables）的表示方式，例如 `λx.x`。

## 二、支援的語法

| 寫法 | 意義 | 範例 |
|---|---|---|
| `x` | 變數 | `x` |
| `\x.M` 或 `λx.M` | Lambda 抽象式 | `\x.x` |
| `M N` | 函式應用 | `(\x.x) y` |
| `(M)` | 使用括號改變優先順序 | `((\x.\y.x) a) b` |

應用式採用左結合；若要將抽象式放在應用式內，請使用括號。

## 三、如何執行

需要安裝 Python 3，不需要安裝額外套件。

```bash
python lambda_interpreter.py
```

執行後可以選擇內建範例，或直接輸入自己的 Lambda Calculus 表達式。直接按 Enter 時會使用範例 2。

## 四、內建範例

### 範例 1：Identity function

輸入：

```text
(\x.x) y
```

計算：

```text
Step 0: (λx.x) y
Step 1: y
```

最終結果為 `y`，代表 Identity function 會原樣回傳輸入。

### 範例 2：避免變數捕獲

輸入：

```text
(\x.\y.x) y
```

這個範例會展示 α-改名。因為代入的 `y` 是自由變數，如果直接放進 `λy.x` 的本體，就可能被內層的 `λy` 捕獲。

因此，解譯器先把內層變數改名成 `y_1`，再進行代入。

結果相當於：

```text
λy_1.y
```

這個過程保留了原本自由變數 `y` 的意義。

### 範例 3：多步 β 化簡

輸入：

```text
(\x.x x) (\y.y)
```

會分步化簡，最後得到 Identity function：

```text
λy.y
```

### 範例 4：選出第一個參數

輸入：

```text
((\x.\y.x) a) b
```

結果為 `a`。這個範例展示函式可以接收兩個參數，最後回傳第一個參數。

## 五、主要程式設計

### 1. 表達式結構

程式以三種節點表示 Lambda Calculus：

- `Var`：變數。
- `Abs`：抽象式，包含繫結變數與函式本體。
- `App`：函式應用，包含函式與引數。

### 2. Parser

解譯器先將輸入切成 token，再依據語法規則建立表達式結構。

若括號、變數或抽象式格式錯誤，程式會顯示錯誤訊息。

### 3. β-reduction

β 化簡的基本規則是：

```text
(λx.M) N → M[x := N]
```

也就是把引數 `N` 代入函式本體 `M` 中所有不受內層同名繫結變數限制的 `x`。

### 4. α-改名與避免變數捕獲

代入前會檢查自由變數。如果引數中的自由變數會被函式本體內的變數捕獲，程式會先將內層繫結變數改名，例如把 `y` 改成 `y_1`，確保代入後的意義正確。

### 5. 完整計算過程

程式採用 normal-order（最左外層）化簡順序，每次顯示：

- 目前的完整表達式。
- 正在執行的 β-reduction 說明。
- 必要時的 α-改名步驟。
- 化簡後的完整表達式。

若到達 β-正規形就輸出最終結果。為避免無限化簡，最多執行 100 步；達到上限會顯示停止訊息。

## 六、計算限制

本作業支援變數、Lambda 抽象式與函式應用，並採用 named-variable 表示法。

目前沒有內建數字、加減法或命名函式定義，這些內容可再自行擴充。

有些 Lambda 表達式不會終止，例如 Ω：

```text
(\x.x x) (\x.x x)
```

對這類輸入，程式會在達到最大步數後停止並顯示目前結果。

## 七、AI 使用說明

本作業在 AI 協助下完成初版設計，包括語法解析、抽象式／應用式資料結構、β-reduction、α-改名、防止變數捕獲、計算步驟輸出與測試範例。

完成後應實際執行程式，檢查每個範例的輸入、化簡過程與結果，並依課程要求修改或補充自己的理解。

## 八、結論

本程式展示 Lambda Calculus 的基本計算方式：透過函式應用觸發 β-reduction，將引數代入函式本體，逐步把表達式化簡。

為了確保變數的意義不會改變，程式也處理 α-改名和變數捕獲問題。每一步都會印出完整表達式與操作說明，方便觀察 Lambda Calculus 的運算流程。
