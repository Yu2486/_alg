# 作業二：`iter_framework.py` 迭代法框架說明

## 一、作業目的

本作業主要是了解迭代法（Iteration Method）的基本概念，並閱讀 `iter_framework.py` 程式，理解如何將重複性的迭代流程設計成一個可以重複使用的「框架（Framework）」。

一般的迭代法會先給定一個初始值，利用計算公式求出下一個近似值，再使用新的近似值繼續計算，直到結果符合停止條件為止。

迭代的基本形式可以表示為：

```text
x(n+1) = g(x(n))
```

也就是利用目前的 `x(n)`，計算下一次的 `x(n+1)`。

---

## 二、迭代法的基本概念

假設我們要解一個方程式：

```text
f(x) = 0
```

可以將它改寫成固定點形式：

```text
x = g(x)
```

接著由一個初始值 `x0` 開始，不斷計算：

```text
x1 = g(x0)
x2 = g(x1)
x3 = g(x2)
...
```

直到前後兩次的結果非常接近為止。

常見的停止條件為：

```text
|x(n+1) - x(n)| < ε
```

其中：

* `x(n)`：目前的近似值
* `x(n+1)`：下一次的近似值
* `ε`：允許的最大誤差

當兩次計算結果的差距小於允許誤差時，就可以認為結果已經收斂。

---

## 三、為什麼需要 Iteration Framework？

如果每一道迭代法題目都自己撰寫完整的迴圈，會產生很多重複的程式。

例如：

```python
x = x0

for i in range(max_iter):
    new_x = update(x)

    if abs(new_x - x) < epsilon:
        break

    x = new_x
```

雖然不同的數學問題所使用的公式不同，但是「重複計算」、「計算誤差」、「判斷是否停止」等工作其實都非常類似。

因此，可以把這些共同的部分整理成一個「迭代框架」。

框架的概念就是：

```text
             ┌────────────────────┐
             │    Iteration       │
             │      Framework     │
             └─────────┬──────────┘
                       │
                       ▼
             計算下一個近似值
                       │
                       ▼
                計算目前誤差
                       │
             ┌─────────┴─────────┐
             │                   │
          尚未收斂             已經收斂
             │                   │
             ▼                   ▼
          繼續迭代            回傳答案
```

如此一來，使用者只需要提供「如何計算下一個值」，其他迭代控制工作交給 framework 負責。

---

## 四、迭代框架的主要流程

一般迭代框架的處理流程如下：

### Step 1：設定初始值

首先指定一個初始猜測值：

```python
x = x0
```

初始值會影響迭代過程以及收斂速度。

---

### Step 2：計算下一個值

利用更新公式產生新的近似值：

```python
new_x = update(x)
```

其中 `update()` 可以代表不同問題所使用的數學公式。

---

### Step 3：計算誤差

比較前後兩次的結果：

```python
error = abs(new_x - x)
```

如果誤差已經非常小，就代表結果已經接近真正答案。

---

### Step 4：判斷是否收斂

例如設定：

```python
epsilon = 1e-10
```

當：

```python
error < epsilon
```

就停止迭代。

---

### Step 5：更新目前結果

如果還沒有收斂，就把新的答案當成下一次迭代的目前值：

```python
x = new_x
```

然後繼續重複以上步驟。

---

### Step 6：限制最大迭代次數

為了避免某些不收斂的問題造成無限迴圈，通常還會設定最大迭代次數：

```python
max_iter = 100
```

表示最多執行 100 次。

---

## 五、迭代法的核心程式概念

一個一般化的迭代流程可以表示為：

```python
x = x0

for i in range(max_iter):

    new_x = update(x)

    error = abs(new_x - x)

    if error < epsilon:
        return new_x

    x = new_x
```

這段程式可以看成迭代 framework 的核心概念。

其中：

```text
x0
```

是初始值。

```text
update(x)
```

負責計算下一個值。

```text
error
```

負責判斷目前是否已經收斂。

```text
epsilon
```

代表允許的誤差範圍。

```text
max_iter
```

代表最多允許執行幾次。

## 六、使用 `x = cos(x)` 作為迭代範例

為了說明迭代法，可以使用：

```text
x = cos(x)
```

作為範例。

將它視為固定點問題：

```text
x = g(x)
```

因此：

```text
g(x) = cos(x)
```

迭代公式為：

```text
x(n+1) = cos(x(n))
```

假設一開始：

```text
x0 = 0.5
```

則：

```text
x1 = cos(0.5)
x2 = cos(x1)
x3 = cos(x2)
...
```

持續迭代之後，結果會逐漸接近：

```text
x ≈ 0.7390851332
```

因此，程式可以透過反覆套用 `cos()` 來取得方程式的近似解。

---

## 七、框架化設計的優點

### 1. 程式碼可以重複使用

同一套迭代控制流程，可以套用到不同問題。

例如第一個問題：

```python
new_x = cos(x)
```

另一個問題可能是：

```python
new_x = (x + 2 / x) / 2
```

雖然數學公式不同，但是迭代流程仍然相同。

因此不需要重新撰寫整個迴圈。

---

### 2. 降低程式重複

將共同的迭代流程集中管理，可以避免每個程式都重複寫：

```python
while ...
```

或：

```python
for ...
```

等控制程式。

---

### 3. 容易維護

如果未來需要修改停止條件，例如從：

```python
epsilon = 1e-10
```

改成：

```python
epsilon = 1e-8
```

只需要修改框架中的相關設定即可。

---

### 4. 容易擴充

增加新的數學問題時，只需要提供新的更新函式。

例如：

```python
def update(x):
    return cos(x)
```

框架本身不需要重新設計。

---

## 八、迭代框架的抽象概念

這個程式最重要的觀念，就是把：

> 「如何計算下一個答案」

與：

> 「如何控制整個迭代過程」

分離。

可以將它表示成：

```text
問題本身
   │
   ▼
更新公式 update()
   │
   ▼
Iteration Framework
   │
   ├── 計算新值
   ├── 計算誤差
   ├── 判斷收斂
   ├── 計算迭代次數
   └── 控制停止
```

這是一種常見的程式設計方式，也就是將「演算法的核心邏輯」與「控制流程」分開。

---

## 九、停止條件的重要性

迭代法不一定會收斂。

如果沒有停止條件，當計算結果一直無法達到要求時，程式可能會一直執行。

因此至少需要兩種控制：

### 誤差停止條件

```python
abs(new_x - x) < epsilon
```

當前後兩次的結果非常接近時，表示已經收斂。

### 最大迭代次數

```python
max_iter = 100
```

即使沒有收斂，達到最大次數後也要停止。

因此：

```text
誤差條件
+
最大迭代次數
```

可以讓程式更加安全。

---

## 十、可能造成不收斂的原因

並不是所有迭代公式都一定可以得到答案。

可能造成不收斂的原因包括：

### 1. 初始值不適當

不同的初始值可能會造成不同的迭代結果。

### 2. 更新公式不適合

某些公式本身可能會造成結果越來越偏離答案。

### 3. 發散

每一次計算之後，結果不是越來越接近，而是越來越遠。

### 4. 收斂速度太慢

雖然最後可能會收斂，但是需要非常多次迭代。

因此使用迭代法時，不只是要確認程式可以執行，也需要注意數學上的收斂性。

```text

      │

```

## 十二、程式學習重點

透過 `iter_framework.py` 可以學習到以下幾個重要的程式設計概念：

### 1. 迭代法

透過重複計算來逐漸逼近答案。

### 2. 函式化

將不同功能拆成不同函式，使程式更容易閱讀與使用。

### 3. 抽象化

把共同的流程抽出來，不需要每個問題重新撰寫完整程式。

### 4. 程式重用

同一個 framework 可以處理不同的迭代問題。

### 5. 誤差控制

利用誤差判斷是否已經達到要求的精度。

### 6. 防止無限迴圈

透過最大迭代次數限制程式執行範圍。

## 十三、結論

`iter_framework.py` 的主要概念，是將迭代法中共同的計算流程整理成一個可以重複使用的框架。

傳統寫法通常需要針對每一個問題重新撰寫迴圈，而 Framework 的方式則可以將：

```text
「計算下一個值」
```

和：

```text
「控制迭代流程」
```

分開。

這樣的設計可以減少重複程式碼，也能提高程式的可讀性、維護性與重複利用性。

本次作業除了學習迭代法之外，也讓我了解程式設計中的「抽象化」與「模組化」概念。當不同問題具有相同的處理流程時，可以將共同部分整理成 Framework，使程式更加有結構。

## 十四、簡單範例

以下是一個使用固定點迭代求解：

```text
x = cos(x)
```

的簡單 Python 程式：

```python
import math

x = 0.5
epsilon = 1e-10
max_iter = 100

for i in range(max_iter):

    new_x = math.cos(x)

    error = abs(new_x - x)

    if error < epsilon:
        print("答案 =", new_x)
        print("迭代次數 =", i + 1)
        break

    x = new_x
```

執行後會得到接近：

```text
答案 = 0.7390851332
```

這個例子可以用來理解 `iter_framework.py` 所要表達的核心概念：**重複計算、檢查誤差、判斷收斂，以及限制最大迭代次數。**
