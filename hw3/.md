# 第三週習題：列舉＋暴力法解 SAT 問題

## 一、作業目的

本作業使用列舉法（Enumeration）與暴力法（Brute Force）解決布林可滿足性問題（SAT）。

程式會找出公式中的所有變數，列舉每一種 True 和 False 的組合，建立真值表，並判斷是否存在一組指派使整個公式為 True。

## 二、SAT 是什麼？

SAT（Boolean Satisfiability Problem）是判斷一個布林公式是否存在一組變數指派，使公式結果為 True 的問題。

- 如果存在至少一組指派讓公式為 True，稱為 SAT。
- 如果所有指派都讓公式為 False，稱為 UNSAT。

本程式使用 CNF（合取範式）表示公式。

- 一個子句中的變數使用 OR（或）連接。
- 不同子句之間使用 AND（且）連接。
- `A` 代表變數 A。
- `!A` 代表 NOT A，也就是 A 的否定。

例如：

```text
(A OR B) AND (!A OR C) AND (!B OR !C)
```

## 三、程式輸入方式

執行程式：

```bash
python sat_truth_table.py
```

每一行輸入一個子句，子句內的變數用空白分隔。輸入空白行代表結束。

例如：

```text
A B
!A C
!B !C

```

代表：

```text
(A OR B) AND (!A OR C) AND (!B OR !C)
```

如果一開始直接按 Enter，程式會自動使用內建範例。

## 四、演算法步驟

1. 讀取 CNF 公式中的所有子句。
2. 找出公式裡所有變數，並依照字母排序。
3. 假設有 n 個變數，使用 `itertools.product()` 列舉所有 True／False 組合，共有 `2^n` 種。
4. 對每一種指派，計算每個子句的結果。
5. 子句內使用 OR，所有子句之間使用 AND。
6. 將每一組指派與運算結果印成真值表。
7. 如果至少有一列使整個公式為 True，結果就是 SAT；否則就是 UNSAT。

## 五、範例與執行結果

範例公式：

```text
(A OR B) AND (!A OR C) AND (!B OR !C)
```

三個變數共有：

```text
2^3 = 8
```

種可能指派。

其中兩組滿足指派為：

```text
A=False, B=True, C=False
A=True, B=False, C=True
```

因此這個公式的結果是：

```text
SAT（公式可滿足）
```

程式會列印完整真值表，並用 SAT 標記每一列符合公式的指派。

## 六、複雜度分析

假設公式有 `n` 個變數，全部子句加起來共有 `L` 個 literal。

每個變數都有 True 和 False 兩種選擇，因此需要檢查：

```text
2^n
```

種指派。

每一種指派都需要檢查公式中的 literals，因此：

- **時間複雜度：** `O(2^n * L)`
- **空間複雜度：** `O(n + L)`，不計輸出。

變數數量增加時，組合數會快速增加：

| 變數數量 n | 指派總數 2^n |
|---:|---:|
| 3 | 8 |
| 10 | 1,024 |
| 20 | 1,048,576 |
| 30 | 1,073,741,824 |

因此，暴力列舉法容易理解，也能找到所有滿足指派，但變數數量很大時，執行時間會快速增加。

## 七、結論

本作業使用系統性的列舉方法，將所有變數的 True 和 False 組合列出，逐一建立真值表，藉此判斷布林公式是否可滿足。

這個方法可以找到所有滿足公式的指派，也可以判斷公式是否為 UNSAT。

不過，因為 n 個變數會產生 `2^n` 種組合，所以時間複雜度是指數級的。當變數越多時，需要檢查的可能性就越多，執行速度也會明顯變慢。
